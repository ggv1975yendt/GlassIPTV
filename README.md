# Промостраница Glass IPTV

Статическая страница: index.html, style.css, translations.js, app.js, nature.svg, stadium.svg. Сборка и внешние зависимости не нужны. RU/EN выбирается кнопкой, выбор хранится локально; при первом посещении учитывается язык браузера.

Для локального просмотра запустите HTTP-сервер из корня проекта и откройте /promo/index.html. Кнопки APK ссылаются на ../releases/Glass-IPTV-1.3.26-release.apk. При будущем размещении на хостинге нужно предоставить APK по этому пути или изменить обе ссылки скачивания. Публикация не выполнялась.

Иллюстрации режимов интерактивны, но не воспроизводят реальные потоки. Все тексты перевода находятся в translations.js; поведение — в app.js.

12 октября 2026: актуализированы оба языка, добавлены родительский контроль и каталог из девяти разделов со всем основным функционалом. Обновлены PiP, управление OK, диагностика и ограничения UHD/фоновой записи. Инвентаризация возможностей: reports/promo-feature-inventory-2026-10-12.md в корне проекта.
