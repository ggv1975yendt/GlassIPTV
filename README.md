# Glass IPTV 1.3.42

В «Интерфейс → Темы» доступны пять готовых тем и Кастом: цвета панелей, текста, заливки и рамки фокуса, толщина рамки. Для каждого цвета — шесть готовых цветных кружков и крайний справа «+» для ручного HEX. Толщина рамки настраивается отдельно. Предпросмотр применяется до сохранения; отмена оставляет прежнее оформление. Прозрачность и масштаб настраиваются в прежних пунктах «Интерфейса».

Для каждого источника единая «Периодичность обновления источника»: при запуске, раз в день, раз в неделю или выкл. Отдельный переключатель запуска убран. Проверка выполняется при запуске и возврате из фона, по местной календарной дате последнего успешного обновления; недельный срок — 7 дней. Фонового таймера нет, ручное обновление сохранено.

Сенсорное управление включено по умолчанию: на телефоне доступны касания кнопок, выделение и вставка текста в поля. Для режима только D-PAD отключите «Сенсорное управление» в скрытых настройках. Открытие: Settings → выделить «О программе» → удерживать OK 10 секунд → Скрытые настройки. Переключение действует сразу и сохраняется; сброс скрытых настроек снова включает касания. Экранный D-PAD доступен в обоих режимах.

Скачивание EPG мягче реагирует на начало просмотра: 5 секунд без снижения скорости по сигналам плеера, новый замер при каждой попытке, нижняя граница искусственного лимита 512 КиБ/с. После 15 секунд благополучного воспроизведения скорость снова может повышаться. В фоне скачивание по-прежнему без ограничения. Сетевое ожидание данных EPG увеличено с 30 до 90 секунд; общего ограничения длительности загрузки нет. Диагностика записывает объём, время, лимит и тип исходной ошибки без адресов и сообщений исключений. Причина наблюдавшегося обрыва около 50 секунд пока требует журнала устройства.

В настройках EPG каждого источника — единая «Периодичность обновления»: «При запуске», «Раз в день», «Раз в неделю» и «Выкл.». Отдельного переключателя запуска больше нет. Ежедневное обновление выполняется при первом открытии приложения в новой местной дате после последнего успешного обновления; недельное — при первом открытии спустя 7 календарных дней, без привязки к часу. Возврат из фона тоже проверяет срок, поворот экрана — нет. Фоновый таймер EPG отменён. Ручное обновление и отдельная опция «После обновления каналов» сохранены; они могут обновлять EPG раньше срока.

Поиск передач читает совпадения одним проходом на источник, без повторной фильтрации и сортировки базы для каждой порции. SQL можно отменить; после 30 секунд ожидания предлагается повторить поиск. В результатах обычный OK открывает меню действий. Если передача ещё не началась или архив недоступен, можно открыть прямой эфир её канала.

Исправлен сброс результатов поиска при фоновом обновлении EPG. Найденные строки, загруженные страницы и фокус сохраняются. Новые данные можно применить кнопкой «Обновить результаты» в конце списка; новый запрос или смена фильтра сразу запускает новый поиск. Обновления EPG больше не затрагивают поиск каналов.

APK: `releases/Glass-IPTV-1.3.42-release.apk` — темы оформления и периодичность обновления источников. Подпись прежняя. Проверка на приставке ещё требуется.

В меню найденной передачи (обычный OK) появился пункт «Добавить в закладки». Сохраняется начало выбранной передачи и её канал, текущий просмотр продолжается. Закладка доступна для каналов с архивом; будущую передачу можно сохранить заранее и открыть после её начала. Найти сохранённое: удержание ↑ → «Закладки». При открытии действует прежний настроенный отступ закладок.

Открытие поиска: во время просмотра удерживайте ↓, в нижней панели нажмите → один раз (с «Телегида» на «Поиск») и OK. На телефоне используйте экранный D-PAD. Также доступно MENU → Поиск на пульте с этой кнопкой.

В поиске: выберите «Каналы» или «Передачи», область источников и фильтр времени. OK на строке запроса открывает встроенную клавиатуру RU/EN; можно вводить и физической клавиатурой. Назад закрывает клавиатуру, затем поиск. Результаты загружаются по 40 кнопкой «Показать ещё». Обычный OK на найденном канале или передаче открывает меню основного/дополнительного окна; у передачи также есть закладка. Удержание OK на передаче тоже поддерживается. Поиск использует загруженную EPG и доступный по сроку архив; запрос и выбранный результат сохраняются в текущей сессии.

В 1.3.32 касание экрана телефона только показывает D-PAD; управление выполняется его кнопками, включая длительное OK. Список возвращается к текущему каналу и программе, активная панель сохраняет фокус. Уменьшена работа UI поверх видео; плавность UHD нужно проверить на приставке.

В 1.3.31 диагностика перенесена в скрытые настройки. В Settings выделите «О программе» и непрерывно удерживайте кнопку OK пульта (физического или экранного) не менее 10 секунд. Появится пункт «Скрытые настройки»; после нового запуска приложения он снова скрыт, сохранённые значения остаются. Короткое нажатие открывает сведения о программе.

Доступны отступ закладок, размер пакета EPG, запас старта записи и параметры PiP: ожидание, число повторов, автозакрытие, предпочтительное качество, буфер. Прежние значения сохранены как стандартные. «Настойчивый запуск» задаёт 45 секунд ожидания, 5 повторов и сохранение окна при ошибке дополнительного канала; защита основного канала при нехватке ресурсов остаётся. Для применения всех параметров PiP перезапустите приложение. Качество ограничивается только при наличии подходящего варианта потока; настройки не добавляют аппаратных возможностей декодеру. Сброс скрытых параметров требует повторного подтверждения и не затрагивает плейлисты.
В 1.3.30 запись прямого TS переподключается после обрыва или закрытия соединения сервером. HLS повторяет неудачные запросы плейлиста/сегмента, проверяет сохранённый префикс сегмента по SHA-256 и дописывает только новые целые пакеты. До пяти повторов с задержками 1/2/4/8/10 секунд; поступление новых данных TS восстанавливает бюджет повторов. Ручная остановка отменяет чтение и ожидание. После переподключения прямого эфира возможен пропуск контента: при сохранении показывается предупреждение о неполной записи. Ошибки накопителя не маскируются сетевыми повторами. В диагностике добавлены причины повторов и завершения, без адресов потоков.

В 1.3.29 основной плеер получает обычный профиль буфера после обмена с PiP; плееры и поверхности при обмене сохраняются. Повтор подключения действительно переоткрывает источник, сохраняя позицию/паузу архива и файлов; автоматические попытки ограничены тремя. После остановки/освобождения плеера сбрасывается состояние фонового бюджета EPG. Устранена ошибка Lint в начальном фокусе каналов, удалены неиспользуемые объявления. Диагностика дополнена поколением источника, результатом переиспользования и освобождением видеодекодера. Причина квадратов на устройстве пока не подтверждена; алгоритм non-IDR и тип видеоповерхности не менялись.

В 1.3.28 открытие закладки с пробной поправкой −20 секунд; сохранённое время не меняется. Запись по расписанию начинается за 30 секунд до передачи, завершается по EPG; запас учитывается при проверке пересечений. Точность на архиве провайдера требует проверки.

Новые изменения: отключение обновлений EPG отменяет активные/ожидающие запросы и отложенный повтор. Разрешение автоматического задания перепроверяется перед исполнением. Импорт EPG публикует пакеты примерно по 2000 передач на границе завершённого блока канала.

При включении PiP текущий плеер сохраняется в дополнительном окне, предыдущий канал открывается в основном. При отсутствии предыдущего канала используется копия текущего; настройка положения/размера PiP сохраняет прежний предпросмотр. PIN проверяется до смены окон.

На каналах с архивом: Инструменты → Добавить закладку. Записи и планы → вкладка «Закладки» → открыть или удалить. Сохраняется момент эфира/паузы/архива; закладки переживают перезапуск и проверяют доступность архива и PIN.

В 1.3.27 во время просмотра панели и фокус кнопок появляются без анимации, чтобы уменьшить работу UI поверх видео. Автоповторы ↑/↓ в каналах ограничены интервалом 140 мс; отдельные нажатия мгновенны. Неизменные параметры видео больше не вызывают повторную настройку его окон. Реальное устранение пауз на UHD ещё требует проверки.

В 1.3.26 уменьшена работа панели каналов при быстром перемещении: программа и описание обновляются через 220 мс после остановки фокуса, EPG строк загружается пакетом для видимой области. Короткое OK и переход к передачам используют выбранный канал сразу. Высота строк не меняется при появлении EPG. Плавность видео на приставке требует проверки.

Промостраница `promo/index.html` обновлена на RU/EN: полный каталог возможностей, PiP, родительский контроль, диагностика и ссылка на актуальный APK.

**Settings → Скрытые настройки → Диагностика** включает журнал без перезапуска. По умолчанию выключена, выбор сохраняется. При выключении сбор прекращается и фоновый поток завершается после финальной выгрузки. При включении журналы пишутся в **Download/GlassIPTV** раз в 5 секунд. На Android 8–9 разрешите доступ к хранилищу. После сбоя повторно откройте приложение на 10 секунд и передайте последние два TXT. Адреса потоков, PIN и сообщения исключений не записываются. Экспортированные файлы можно удалить вручную; новая специальная диагностическая сборка больше не нужна.

В 1.3.25 улучшено восстановление UHD/PiP: при ошибке основного декодера пробуется облегчить дополнительный поток; при отсутствии вариантов и подтверждённой нехватке ресурсов или повторной ошибке запуска PiP освобождается раньше. Учёт пропусков кадров теперь учитывает длительность события и fps. Журнал показывает доступные качества и числовые ошибки декодеров. Два UHD без более лёгких вариантов по-прежнему зависят от аппаратных ресурсов. Реальная проверка нового алгоритма требуется.

В 1.3.23 основное видеополотно сохраняется с запуска приложения при включении/закрытии PiP. Убраны взаимные перезапуски плееров и ограничена частота автоматического снижения качества. Это исправление потенциальных причин мигания и вылета, отмеченных для FHD/SD в 1.3.22; результат требуется проверить на приставке. TextureView теперь используется постоянно, включая одиночный просмотр; ограничения GPU/HDR/4K описаны в VALIDATION.md.

В 1.3.22 плеер автоматически выбирает более лёгкую доступную видеодорожку при устойчивых потерях кадров, длительной буферизации или ошибке видеодекодера. При запуске PiP предпочитаются варианты до 720p / 3 Мбит/с; обмен окнами качество не переключает. Снижение возможно только при наличии альтернатив в потоке провайдера — единственный UHD-поток не перекодируется. Выбранное понижение действует до нового запуска источника. PiP не закрывается при первой сетевой ошибке, а даёт плееру выполнить ограниченные повторы.

В 1.3.21 обмен основного окна и PiP сохраняет плееры и их видеополотна, меняя размеры и положение. Звук идёт из основного окна; выбранные дорожки сохраняются. Единичный всплеск пропущенных кадров больше не отключает PiP. При первом включении PiP возможна пауза из-за перехода на TextureView; фактическую плавность и нагрузку тяжёлых каналов нужно проверить на устройстве.

Настройки положения и размера PiP перенесены в **Settings → Интерфейс → Картинка в картинке**. Пункт из основного списка настроек убран; возврат назад идёт в «Интерфейс».

В 1.3.20 при долгом **OK на защищённой передаче** порядок такой: **PIN → разрешение просмотра → выбор основного окна или PiP**. При отмене PIN меню не открывается. Если доступ уже разрешён в текущей сессии, повторный PIN не нужен.

В 1.3.19 короткое **OK** сразу запускает выбранный канал или передачу в основном окне (эфир/доступный архив), с проверкой PIN. Долгое **OK на канале** открывает прежнее меню с новыми пунктами выбора основного окна или PiP; долгое **OK на передаче** — выбор окна. Для будущей передачи остаются напоминания и запланированная запись.

В 1.3.18 долгое **OK на телепередаче** открывает выбор: **основное окно** или **дополнительное окно (PiP)**. Доступно в телегиде, панели передач канала и поиске. Текущая передача открывается в эфире, прошедшая — из доступного архива. Запуск в PiP сохраняет просмотр в основном окне; уже открытое PiP меняет содержимое. Для защищённых каналов требуется PIN. У будущих передач остаются напоминания и запланированная запись.

В 1.3.17 добавлена **ручная PIN-защита**. Начальный PIN — **0000**. Settings → Родительский контроль → Изменить PIN: текущий код, новый код, повтор нового. Долгое OK на канале или категории позволяет включить/снять защиту после ввода PIN. Защита группы действует и через избранное и «Мой плейлист».

При просмотре после правильного PIN выберите «только этот канал» или «все защищённые каналы». Разрешения сбрасываются при выходе/уходе в фон; в настройках есть «Заблокировать снова». Для изменения правил PIN нужен заново. Защита сторонних видео не предусмотрена; ограничения записей и проверки устройств — VALIDATION.md.

В 1.3.16: **Параметры → Картинка в картинке → Размер**. Начальная ширина 25% экрана; ←/→ меняют её с шагом 5%, OK сохраняет, Назад отменяет. Диапазон 10–75% с ограничением по высоте, пропорции 16:9. Готовые APK хранятся в `releases/`, вне очищаемого каталога сборки.

В 1.3.14 добавлен редактор **Настройки → Мой плейлист**. Выберите группу для переименования или удаления; в начале списка доступно создание группы. Удаление с подтверждением затрагивает только группу и её подборку, сохраняя каналы источников и остальные группы. Эти действия доступны и в меню группы при добавлении канала.

В 1.3.13 долгое OK на выбранном канале открывает меню из двух действий: добавить/убрать из избранного и добавить в группу «Моего плейлиста». Короткое OK по-прежнему запускает канал. Убраны повторные пункты «Мой плейлист» в выборе источников и на панели ввода номера. Исправлены символы цифровой панели и подпись выбранного виртуального источника. Фокус каналов, передач, описаний, кнопок и полей ввода имеет общую форму с закруглением 12 dp.

В 1.3.12 появился **«Мой плейлист»** — виртуальный источник с собственными категориями для каналов разных провайдеров.

- Добавление: удерживайте OK на канале в списке → «Добавить в группу «Моего плейлиста»». Для текущего канала тот же пункт есть в панели инструментов. Выберите категорию или создайте новую; один канал может быть в нескольких категориях.
- Просмотр: панель выбора источников → «Мой плейлист» → категория или «Все». Каналы переключаются внутри подборки, даже если их источники разные. Ввод номера также поддерживает «Мой плейлист».
- Управление каналом: удержание OK → «Добавить в группу «Моего плейлиста»» → отмеченная категория → удалить из категории, переместить, поднять/опустить. Исходный канал не удаляется.
- Категории: откройте «Настройки → Мой плейлист» или в панели категорий виртуального источника выберите «Управление категориями» для создания, переименования или удаления. Удаление требует подтверждения и убирает только подборку этой категории.
- EPG, архив и запись используют исходный канал. Исчезнувшая ссылка помечается недоступной и остаётся для ручной очистки. При возвращении прежнего ID канал становится доступен снова; при смене ID его нужно добавить заново.


В 1.3.11 раздел «Источники» сразу показывает список. У каждого источника собственное подменю: редактирование, обновление при запуске, периодическое расписание, ручное обновление каналов и удаление. Старые общие настройки переносятся каждому источнику, после чего меняются независимо. В редакторе доступны название и адрес, а для Xtream — логин и пароль; источник сохраняет свой ID. После сохранения обновляются только его каналы. Связанная EPG обновляется согласно её отдельной настройке «после каналов». Периодическое расписание независимо от запуска приложения.

В 1.3.10 каждая EPG получила отдельное подменю: адрес, обновление при запуске, после каналов, периодическое расписание и «Обновить сейчас». Старые значения сохраняются при переносе. Выключенный запуск больше не обходится автоматическим возобновлением незавершённого XMLTV; периодическое обновление настраивается отдельно. Удаление источника отменяет связанную обработку EPG. Адрес источника телеканалов можно изменить с последующим обновлением каналов. Убрана лишняя работа с несопоставленными каналами XMLTV и задержки без воспроизведения; реальная скорость зависит от источника и устройства.

В телегиде ←/→ переходят по передачам, ↑/↓ — по каналам. Трёхчасовое окно сдвигается при выходе выбранной передачи за границу; OK открывает именно её. При возврате из меню передачи сохраняются канал и позиция. Надпись IPTV в верхнем углу удалена.

В 1.3.9 адрес EPG виден открытым текстом, фон контейнера экранного пульта полностью прозрачен. Инфопанель архива обновляет передачу по времени воспроизведения. Исправлено состояние списков при удалении заданий, добавлены вкладки источников в панель ввода номера (цифры сохраняются при смене источника). Для низкого горизонтального экрана телефона уменьшены отступы, учтены системные области и добавлена прокрутка меню с удержанием фокуса в видимой области. Проверка реальных устройств ещё требуется — см. VALIDATION.md.

В 1.3.8 добавлены напоминания и запись будущих передач по расписанию. Выберите передачу в телегиде или панели каналов и передач: доступны независимые действия «Напомнить» и «Записать по расписанию», а также их отмена. Телегид показывает 3 часа с отметками каждые 30 минут.

Удерживание ↑ открывает верхнюю панель: «Записи», «Напоминания», «Запланированные записи». Стрелки ←/→ переключают вкладки из любого места панели, ↑/↓ перемещают по списку, OK открывает действия. Позиции списков сохраняются при переключении вкладок. Задания можно удалить; для выполняющейся записи предлагается остановка с финализацией.

Напоминание появляется за минуту до начала по центру экрана, без настройки положения, с кнопками переключения на канал и закрытия. В фоне используется системное уведомление; центральное окно доступно при возвращении в приложение до конца передачи. Устаревшие напоминания автоматически удаляются по окончании передачи и при следующем запуске.

Расписание хранится в Room (миграция 3→4), время фиксируется при выборе передачи из EPG. Запись запускается по началу и останавливается с финализацией по окончании передачи. Пересекающиеся будущие задания требуют явного подтверждения замены; выполняющуюся запись автоматически не прерываем. Если канал занят ручной записью в момент старта, задание получает видимую ошибку. Две передачи подряд допускаются; вторая ждёт до 30 секунд завершения первой. Завершённый файл находится в каталоге, ошибки остаются в списке заданий до удаления.

На Android 12+ для планирования требуется системный доступ «Будильники и напоминания»: приложение предложит открыть настройки, после разрешения действие нужно повторить. Восстанавливаются таймеры после перезагрузки, обновления приложения и изменения часов; непосредственно из boot-receiver запись не стартует. Пропущенная целиком передача не записывается задним числом. На выключенном устройстве или после принудительной остановки приложения выполнение не гарантируется; фоновые ограничения прошивки и проверка Mi Box описаны в VALIDATION.md.

При первом запуске после чистой установки предлагается выбрать язык: English или Русский. По умолчанию используется английский, на нём установлен фокус пульта. Выбор сохраняется; позже язык можно изменить в настройках. При обновлении существующий язык сохраняется.

В 1.3.6 исправлены дефекты аудита: идентификация копий записей, коллизии каналов M3U, конкурирующее сохранение настроек источника, обновление удалённых источников, чередующиеся блоки XMLTV, выбор группы другого источника и восстановление архивной позиции. Для HLS/TS включено распознавание non-IDR I-кадров; это устраняет выявленную проблему разбора предоставленного потока. Результаты и ограничения проверки — [в отчёте](reports/fixes-2026-10-06/RESULT.md).

Часы и дата при включённой настройке «Показывать время» отображаются постоянно, включая просмотр со скрытой инфопанелью. Видимость зависит только от этой настройки. Разделитель часов мигает каждые полсекунды, цифры остаются неподвижными.

IPTV-плеер для Android TV, Google TV и телефонов с Android 8.0 (API 26) и новее. Идентификатор приложения: `tv.glass.iptv`, versionCode: 52.

## Возможности

- Источники M3U и Xtream Codes, категории, избранное и история просмотра.
- XMLTV / gzip, значки каналов из EPG, телегид и почасовые интервалы при отсутствии программы.
- Просмотр архива и выбор времени для источников, поддерживающих архив.
- Картинка в картинке; параметры канала: аудиодорожка, ручной системный или программный аудиодекодер, субтитры и формат изображения.
- Управление телевизионным пультом и полупрозрачный Touch D-pad на телефонах.
- Настройки источников, обновления, интерфейса и прозрачности панелей.
- Фоновая обработка с адаптацией нагрузки; ручное обновление EPG отменяет предыдущую обработку и начинает скачивание заново.
- Независимая запись эфира в TS, файловый каталог записей, воспроизведение с паузой/перемоткой и совместный просмотр записи и эфира в PiP.

Инфопанель одинаковой высоты для всех каналов: 20% высоты экрана, в пределах 104–180 dp. Минимум 104 dp применяется на небольших экранах ради читаемости. Слева название канала, текущая передача и прогрессбар; в средней колонке три следующие передачи. Пропорции столбцов слева направо: 40%, 45%, 15% доступной ширины после вычета промежутков. Без EPG на канале с архивом прогрессбар и выбор времени через OK используют текущий почасовой интервал. Наличие архива обозначается значком ↶ справа, над информацией о видео и аудио.

При просмотре архивной передачи в инструментах доступна кнопка «Пауза / Продолжить», также работает Play/Pause пульта. Пауза сохраняется при возвращении в приложение и обмене окнами PiP. Короткое → вне выбора позиции переключает текущий и предыдущий просмотр: канал, архив или видеофайл. Для архива и файла восстанавливаются позиция и пауза; эфир без паузы открывается на текущем времени. История этой пары хранится только до закрытия приложения. При включённом PiP короткое → по-прежнему меняет окна местами.

Прямой эфир можно поставить на паузу только на каналах с архивом (M3U/Xtream). При продолжении открывается архив с сохранённой точки. Учитывается отставание от прямого эфира, если плеер его определяет; иначе используется время устройства. Для Xtream минутный адрес дополняется перемоткой внутри минуты. Конечный архивный фрагмент в основном окне продолжается следующим; при достижении текущего времени включается эфир. Фактическая точность зависит от архива провайдера. На каналах без архива кнопка паузы не отображается.

Для перемотки архива нажмите OK в инфопанели, выберите время стрелками ←/→ по прогрессбару, затем подтвердите OK. «Назад» отменяет выбор. Удерживание ↑ открывает записи, короткое ↑ переключает канал. Часы остаются видимыми при включённой настройке.

## Запись эфира

Запуск записи не ждёт разрешения на уведомления Android 13+: служба запускается до показа диалога. До первых данных показывается «Запуск записи…», затем начинается таймер. Для прямого TS первый полный пакет сразу передаётся в файл; ожидание трёх пакетов и заполнения 64-КБ буфера в начале устранено. Время начала завершённого файла берётся по поступлению первых данных. Сетевое подключение, создание файла на USB и поступление видеокадра всё ещё могут занимать время. Кнопка доступна при выбранном канале прямого эфира независимо от буферизации; запуск недоступен при просмотре файла/архива или незавершённой предыдущей записи. На Android 8–9 первое сохранение в общую память требует разрешения на запись.

Удерживайте ↓ для открытия инструментов и выберите «Начать запись». Инструменты расположены в один ряд, без пункта «Записи»; высота панели — не более 15% экрана. Если ряд не помещается по ширине, он прокручивается горизонтально при навигации. Одновременно записывается один канал; просмотр, переключение каналов и PiP работают независимо. «Остановить запись» сохраняет файл, в том числе после перехода на другой канал. Красная точка и таймер находятся справа от значка архива в правой колонке инфопанели. Во время просмотра архива провайдера запуск записи недоступен.

Удерживание ↑ открывает каталог. Завершённую запись или сторонний видеофайл можно воспроизвести в основном окне или PiP, окна меняются кнопкой «Поменять окна» в инструментах. Инфопанель записи повторяет компоновку эфира: три колонки 40/45/15, информация о записи и потоке. Короткое OK активирует подсвеченный прогрессбар, ←/→ выбирают позицию с шагом 1 секунда; при удержании шаг увеличивается до 5 секунд с восьмого повтора и до 10 секунд с двадцать четвёртого. Повторное OK подтверждает переход, «Назад» отменяет выбор. Без режима выбора стрелки сохраняют обычную навигацию. Пауза доступна в инструментах и клавишей Play/Pause пульта. Дорожки и ручной аудиодекодер доступны через параметры в инструментах. Архивный выбор времени эфира остаётся привязанным к минутам из-за точности URL провайдера; секундный шаг относится к локальным файлам.

Удаление требует подтверждения и удаляет сам файл на носителе. У активной записи в каталоге доступны «Остановить запись» с сохранением файла и «Остановить и удалить» с подтверждением. Обе кнопки остановки — в инструментах и списке — используют один путь сохранения. Он закрывает файл, добавляет время окончания, проверяет обновлённое имя у файлового провайдера и обновляет список; на время завершения повторная остановка недоступна. Ручная и автоматическая остановка завершают файл с временем окончания; при обработанной ошибке сохраняется доступная часть с предупреждением. После аварийного завершения процесса незавершённые файлы остаются в папке и отмечаются как прерванные. Для старого файла без окончания доступно подтверждаемое действие «Завершить сохранённый файл»: окончание оценивается по времени изменения файла; потерянные данные не восстанавливаются. Активные файлы нельзя воспроизводить или завершать вручную.

Каталог показывает видеофайлы непосредственно в выбранной папке, включая сторонние и переименованные. Видео определяется по MIME-типу, расширению, а для неизвестных типов — по доступным медиаданным. Папки, документы и другие распознанные немедиафайлы исключаются; подпапки рекурсивно не обходятся. Записи Glass IPTV отображаются с каналом, временем и состоянием; остальные — с исходным именем и подписью «Видеофайл». Слово partial в произвольном имени не означает прерванную запись. Неподдерживаемый формат не исключает распознанный видеофайл из каталога: при попытке открытия показывается ошибка, сам файл сохраняется. Длительность и дорожки стороннего видео определяет плеер при открытии. Сообщения об окончании записи одноразовые и не повторяются при открытии приложения.

Папка по умолчанию — `Movies/GlassIPTV` основной общей памяти. В настройках → «Записи» можно выбрать другую папку, включая доступный USB, через системный выбор папок. Если прошивка TV не содержит такого компонента, используется папка по умолчанию. Для сторонних видео общей памяти каталог предлагает доступ к хранилищу на Android 8–12 и к видео на Android 13+. Без разрешения Android может показывать только файлы самого приложения или выбранные пользователем видео. MediaStore дополняется доступными файлами папки на Android 11+. Для полного перечисления папки независимо от медиаиндекса выберите её через системный выбор папок (SAF). Каталог обновляется при открытии и возвращении в приложение; сведения не сохраняются в БД и остаются в именах файлов. Очень длинное название канала сокращается до 100 байт UTF-8 перед безопасным кодированием. Если служебное имя потеряно, файл отображается как обычное видео.

Поддерживаются прямой MPEG-TS и незашифрованный HLS с TS-сегментами. Данные сохраняются без декодирования/перекодирования; в HLS выбирается вариант с наибольшим BANDWIDTH среди вариантов без отдельного аудиоплейлиста, начало — последний доступный сегмент. fMP4/DASH, шифрование, отдельное аудио, byte-range и разрывы временной шкалы пока не поддерживаются. Перемотка доступна, когда Media3 определяет временную шкалу файла и хранилище поддерживает произвольное чтение.

Запись использует службу с уведомлением. На Android 15+ действует системный лимит фоновых dataSync-служб; при его достижении выполняется завершение файла. Если накопитель отключён, переименование невозможно или процесс аварийно уничтожен до завершения, метка окончания может не сохраниться. Расписание создаётся по будущей передаче EPG; произвольный пользовательский таймер не добавлен. Совместимость потоков провайдера и USB на Mi Box требует проверки — см. VALIDATION.md.

## Сборка

Нужны JDK 17, Android SDK 37 и Build Tools 36.0.0. Gradle Wrapper 9.6.0 и AGP 9.4.0 закреплены в проекте. Откройте корень проекта в Android Studio. Путь SDK задаётся локально в `local.properties`.

```powershell
.\gradlew.bat :app:assembleRelease
```

Результат: `app/build/outputs/apk/release/app-release.apk`. Release использует R8 и по явному решению пользователя подписывается существующим debug-ключом для личного использования. Это не включает режим отладки в приложении. Для обновления без удаления данных сохраняйте тот же ключ. Путь можно задать параметром `-Pglass.debugKeystore=ПУТЬ`. Ключи и секреты нельзя включать в исходники.

Для отладки: `.\gradlew.bat :app:assembleDebug`. Тесты запускаются только целевым набором по изменяемому механизму, без автоматического полного прогона.
