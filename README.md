# Промостраница Glass IPTV

Статическая страница: index.html, style.css, translations.js, app.js, nature.svg, stadium.svg. Сборка и внешние зависимости не нужны. RU/EN выбирается кнопкой, выбор хранится локально; при первом посещении учитывается язык браузера.

Для локального просмотра запустите HTTP-сервер из корня проекта и откройте /promo/index.html. Кнопки APK ссылаются на ../app/build/outputs/apk/release/Glass-IPTV-1.3.11-release.apk. При будущем размещении на хостинге нужно предоставить APK по этому пути или изменить обе ссылки скачивания. Публикация не выполнялась.

Иллюстрации режимов интерактивны, но не воспроизводят реальные потоки. Все тексты перевода находятся в translations.js; поведение — в app.js.
